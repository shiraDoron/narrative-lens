# Prompt Revision v3 — 30 frozen TRAIN originals

Start with `REPORT_HE.md` after completion. `REVIEW_PACKAGE_30.md` contains Original/v2/v3 and automatic results. For the separately performed external review, use `REVIEW_PACKAGE_BLIND_30.md` to avoid displaying v2, guard scores, authors or narrative proposals. Neither package includes new judgments. They cover exactly the same 30 train sources, not validation/test.

From the repository root, Python 3.11 in the existing study environment:

```powershell
python artifacts/experiments/style_intervention_v2_20261026/train_prompt_revision_v3_30_20261102/run.py --stage all
```

Stages: `prepare`, `generate`, `validate`, `report`. Preparation freezes the same cohort, v2 comparisons and a fresh hash inventory of all pre-existing study artifacts, including uncommitted Error Analysis. The entire v2 prompt is retained as the v3 prefix; only a targeted addendum is appended. `prompt_delta.diff` shows the intervention.

Generation and validation delegate to the unchanged preceding `train_prompt_revision_30_20261101/run.py`, redirecting outputs into this directory. Generator model, native runtime, seed, decoding, output-token budget, original-only request shape, concurrency and automatic checks remain unchanged. Same local Qwen GGUF and llama-server.exe (Windows runtime) and cached MPNet/NER/DeBERTa models are required, as described in predecessor manifests. Runtime/weights/caches are not copied into Git. `--stage all` does not train a classifier. Resumption skips saved candidates; it does not select or improve them by scores.

`report_v3.py` computes inherited style metrics and all 66 explicit features using the same train-original scaling, comparisons, quote diagnostics, hashes, full/less-cued review packages and literal checks of previously identified problem spans. A restored span is a preliminary textual observation, not verified meaning. Metrics from external review of v2 are never transferred to v3. New reviewer fields generated by the inherited validator stay blank.

To recompute only reports from saved rewrites/scores, use `--stage report`. Fresh generation requires a new versioned directory; do not delete or overwrite the retained candidates. The sole intended experimental variable is the prompt. No prompt iteration, threshold tuning, filter changes, retraining, LoRA, human validation, external LLM judging or test evaluation is part of this run. Stop after packaging for separate external review.
